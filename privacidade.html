Política de privacidade do Caderno

Atualizada em 16 de outubro de 2026.

O Caderno é um aplicativo pessoal para Windows, usado só pelo autor, no próprio computador. Não existe servidor do Caderno: o aplicativo fala direto com o Google.

Que dados do Google o Caderno usa

  • Google Tasks: o título, a data e a situação (aberta ou concluída) das tarefas, para mostrar a lista da semana. O Caderno também conclui, reabre e cria tarefas, só quando o usuário pede.
  • Google Agenda: o título, o dia e a hora dos eventos da agenda principal na semana, para mostrar na lista. O Caderno também cria eventos com avisos, só quando o usuário pede.
  • E-mail da conta: para mostrar qual conta está conectada.

Onde os dados ficam

As tarefas e os eventos lidos ficam só na memória do aplicativo, enquanto ele está aberto. O acesso à conta (o token de renovação) fica num arquivo no computador do usuário, cifrado pelo Windows. Nada é enviado a outras pessoas ou serviços, nada é vendido e nada é usado para publicidade.

Como desconectar

No Caderno, em Configurações > Google, "Desconectar" revoga o acesso no Google e apaga o arquivo do computador. O acesso também pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Uso limitado

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
